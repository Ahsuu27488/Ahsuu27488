## 🛠️ Latest: Taskvane

<a href="https://taskvane.ahsandev.site"><img src="https://raw.githubusercontent.com/Ahsuu27488/taskvane/main/website/public/img/og.png" alt="Taskvane: a better Task Manager for Windows 11" width="640"></a>

**[Taskvane](https://github.com/Ahsuu27488/taskvane)** is a free, open-source Task Manager alternative for Windows 11 with CPU and GPU temperatures, power draw in watts and battery health, using about 0.4% CPU.

- Python desktop app with a WebView2 UI, LibreHardwareMonitor sensors in a crash-isolated helper, and process stats from a single `NtQuerySystemInformation` call
- Handles elevation, a signed kernel driver (PawnIO) and scheduled tasks; ships as an Inno Setup installer and a portable zip, with GitHub Actions CI
- [Website](https://taskvane.ahsandev.site) built with Astro, with structured data for search engines and AI assistants
